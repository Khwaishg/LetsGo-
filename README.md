# LetsGo ✈️

**LetsGo** is a travel companion web application that helps people find travel partners and plan trips together. Users can explore trips, connect with people they know, or discover new travel companions based on their preferences.

## 🔗 Project Links

* **GitHub Repository:** https://github.com/Khwaishg/LetsGo-
* **Live Demo:** https://letsgo-2med.onrender.com

## ✨ Features

* **User Authentication:** Sign in to access the website.
* **Travel with Friends:** Explore trips involving people you have connected with.
* **Discover New Travel Companions:** Find trips with people outside your existing connections.
* **Age-Based Filtering:** Filter travel options according to age preferences.
* **Trip Requests:** Accept or reject requests to connect for a trip.
* **My Trips:** View and manage your trips.
* **Chat Feature:** Communicate with travel companions after a request is accepted.

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python, Flask
* **Database:** SQLite
* **Template Engine:** Jinja2
* **Tools:** VS Code, Git, GitHub

## ⚙️ Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Khwaishg/LetsGo.git
   cd LetsGo
   ```

2. Create and activate a virtual environment:

   ```bash
   python -m venv venv
   venv\Scripts\activate
   ```

3. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the Flask application using the appropriate Python entry-point file:

   ```bash
   python app.py
   ```

5. Open the local URL displayed in the terminal, usually `http://127.0.0.1:5000/`.

## 🎯 Project Objective

The goal of LetsGo is to make travelling more social and convenient by helping users find suitable travel companions, coordinate trips, and connect with people they trust.
